# D-FIR Truncated Multiplier Tests

Same dependencies as in test/. Uses test/requirements.txt

```
pip install -r ../requirements.txt
```

Verilator RTL simulation for truncated multiplier.
```
make -B
```

Plots can be generated by first running the RTL simulator (`make -B`) to dump error statistics from simulation, then running `trunc_mult_stats.sh` to dump area statistics from yosys using the Sky130A lib.

Requires Sky130A PDK to be installed using ciel.

```
export SKY130_PDK_VERSION=6d4d11780c40b20ee63cc98e645307a9bf2b2ab8
ciel enable --pdk sky130 $SKY130_PDK_VERSION
```

```
chmod +x trunc_mult_stats.sh
./trunc_mult_stats.sh
```

Generate area vs. error plots from dumped csv's.
```
chmod +x plot_trunc_statistics.py
./plot_trunc_statistics.py
```
